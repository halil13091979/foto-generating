# Sooli

Премиальная AI-платформа для генерации фото и карточек товара для маркетплейсов.

Домен: sooli.ru

## Что включено

- генерация карточек для Wildberries, Ozon, Яндекс Маркета и других площадок
- сценарии: premium studio, editorial, lifestyle, bundle, info graphic
- логика пресетов под форматы и требования площадок
- современный dashboard для работы с товарами и генерацией
- тесты для промпт-логики и экспортных настроек

## Быстрый старт

```bash
npm install
npm run dev
```

## Команды

```bash
npm run dev
npm run build
npm run start
npm run test
```

## Архитектура

- Next.js 14 + React + Tailwind
- генерация промптов и пресетов: `src/lib/marketplace-styles.ts`
- главный интерфейс: `src/app/page.tsx`
- стиль платформы: `src/app/globals.css`

## Дорожная карта

1. Подключение реального AI API генерации изображений
2. Авторизация и личный кабинет
3. Загрузка фото товара и референсов
4. Сборка карточек и пакетная генерация
5. Отчёты, лимиты, billing и команды
6. Синхронизация с CRM, складами и S3
